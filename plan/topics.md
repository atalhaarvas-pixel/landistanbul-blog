# Editorial plan — Land Istanbul blog

Goal: every article must bring leads from one of four groups:
**sell** (people who own property in Turkey and want to sell), **citizenship** (Turkish citizenship by investment),
**apartment** (buying an apartment / home in Istanbul), **land** (buying land / development plots).

Rules for picking the next topic:
1. Rotate segments: never publish the same segment two days in a row; keep the four segments roughly equal each week.
2. Prefer a timely topic when there is real news (new law, fee change, Resmi Gazete decision, market data) — check news first.
3. Never repeat a topic already in `posts/`. Mark a topic `[x]` here when it is published (and add the date).
4. Each topic targets one primary search phrase (below). Use it in the title, first paragraph, one H2 and the meta description.
